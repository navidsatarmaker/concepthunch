# Business Idea Generator

A clean, minimalist web application that suggests actionable business ideas on each tap with **zero repeats**.

## Features
- **Tap to reveal**: Every tap or click on the card reveals a fresh, non-repeated business idea.
- **Zero Repeats Guaranteed**: Uses persistent tracking (`localStorage`) and a shuffled non-repeating queue. Ideas never repeat until you've explored the entire pool.
- **Copy & Share**: Quick buttons to copy the idea to your clipboard or share it directly via the native Web Share API (mobile/desktop).
- **Zero Dependencies**: Pure HTML, CSS, and Vanilla JavaScript.
